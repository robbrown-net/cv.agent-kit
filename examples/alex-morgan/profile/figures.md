## Read this before writing a single number

**If a number is not in the table below, it does not go in a CV, a cover letter or an
application answer.** Not in the summary, not in a bullet, not in an interview prep note.
There is no category of number that is fine to estimate, round up, or reconstruct from
memory of an earlier draft.

**The failure mode is not invention from nothing. It is the near miss.** The usual wrong
number is a plausible neighbour of a real one:

| Drift | Example |
| --- | --- |
| A multiplier read as a percentage | 2x target becomes 200 percent, then 500 percent |
| A duration drifting between drafts | 15 weeks becomes 28 weeks |
| Two live records, neither retired | a budget recorded twice with different values |
| A ratio invented to sound tidier | counts turned into a percentage nobody measured |
| A stale entry outliving its correction | the old count survives in one record |

A near miss is worse than a vague sentence, because it is checkable and it is wrong.
If the exact figure is not here, write the shape of the result without a number, or leave
it out. Never split the difference between two remembered values.

Rules of use:

- Copy the figure column verbatim. Do not re-round, re-unit or convert currency.
- A figure marked **verify** has a structured metric that its own claim text does not
  corroborate. Read the record before using it.
- Check the CONTESTED FIGURES section (if present) before using anything from an employer
  it names.
- Confidence is the bank's own rating. Do not promote medium to high by writing it
  more confidently.
